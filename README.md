**이 프로그램은 클로드의 도움(바이브 코딩을 뜻함)을 전적으로 받아 만들었으며, 실제 사용 중 문제가 생기는지는 제가 직접 써 보며 확인하고 있습니다.**

# S4CCM이란?

S4CCM은 심즈4의 CC템을 정리하고 관리하는 Windows용 프로그램입니다.

Mods 폴더 안의 `.package` 파일을 직접 읽어서 CC템의 종류를 정리해 줍니다.

## 1. 이걸 왜 쓰는 건가요?

CC템을 정리해두기도 귀찮고 뭐하던 CC템인지도 기억하기도 어려워 S4CCM은 아래의 기능을 지원합니다.

### 라이브러리
- CC템의 썸네일을 확인하여 보여줍니다.
- 썸네일은 패키지 안에서 추출하여 썸네일 캐시에서 가져옵니다. 직접 이미지를 지정할 수도 있습니다.
- 포즈 팩은 상세 패널에서 좌우 화살표로 포즈 아이콘을 넘겨 볼 수 있습니다.
- 고화질(HQ) 텍스처가 들어있다면 CC템에 `HQ` 표시가 붙습니다.
- CC템마다 배포 페이지등을 기록 할 수 있게 메모가 가능합니다. 파일을 옮기거나 이름을 바꿔도 메모는 따라갑니다.

### 자동 분류와 자동 정리
- CAS 파츠는 패키지 안의 BodyType(헤어, 상의, 하의, 신발, 귀걸이, 립스틱 등)을 읽어 분류합니다.
- 건축 리소스(벽지, 바닥, 지붕 등), 스킨톤, 슬라이더, 프리셋, 포즈/애니메이션, 게임 모드도 구분합니다.
- 프로그램이 정리한게 마음에 들지 않으시면 언제든 되돌릴 수 있습니다.

### CC 추가
- 파일, 폴더, `.zip` / `.7z` / `.rar` 압축 파일을 창에 끌어다 놓으면 종류를 판정해 알맞은 폴더에 넣습니다.
- 스크립트 모드는 폴더째 넣고, 알려진 모드(MCCC 등)는 이름을 알아보며, 새 버전이면 옛 버전 교체를 제안합니다.
- 트레이 파일(가족, 집, 방)은 Tray 폴더로 넣습니다.

### 도구
- **트레이**: 저장해 둔 가족, 집, 방을 보여 주고, 그 항목에 쓰인 CC를 찾아 줍니다. 이름·설명·대표 사진 바꾸기, "외형만 남기기", CC를 포함한 zip 내보내기를 할 수 있습니다.
    - 대표 사진 바꾸기: 심즈에서 보여지는 대표 이미지를 변경합니다
    - 외형만 남기기: 심을 배포 할 때 스킬이나 추억과 같은 플레이 내용을 지워서 배포 할 수 있습니다
- **Resource.cfg**: 게임이 Mods 폴더를 읽는 규칙과 게임 옵션(모드 허용, 스크립트 모드 허용)을 화면에서 고칩니다.
- **충돌 테스트**: 모드를 절반씩 빼 가며 게임을 망가뜨리는 CC/모드를 찾습니다.
- **중복 검사**: 완전히 같은 파일과, 이름은 달라도 같은 아이템이 들어 있는 파일을 찾습니다.
- **심볼릭 링크**: Mods 폴더를 다른 드라이브로 옮기고, 원래 자리에는 링크를 남깁니다.
    - Mods 폴더는 일반적으로 C드라이브에 위치하며 C드라이브 용량이 부족 할 떄 다른 드라이브로 옮길수 있습니다

## 3. 작동 방식

- 계산하는 부분(패키지 읽기, 분류, 스캔, 파일 이동)은 Rust로, 화면은 C++ Qt 6로 만들었습니다.
- 심즈4의 패키지(DBPF) 파일을 직접 읽습니다. 게임 파일이나 CC 파일의 내용은 고치지 않습니다.
- 파일은 심즈4 폴더 안(`Mods`, `S4CCM_Disabled`, `S4CCM_Quarantine`)에서만 옮기고, 지울 때는 휴지통으로 보냅니다.
- 첫 스캔 뒤에는 바뀐 파일만 다시 읽어서 빠르게 열립니다. 첫 스캔도 여러 파일을 동시에 읽습니다.
- 창으로 돌아올 때 자동으로 다시 스캔하지 않습니다. 목록을 새로 읽으려면 [다시 스캔]이나 `F5`를 누르세요.

## 4. 설치 방법

- [Releases](https://github.com/AiryNyan/S4CCM/releases)에서 내려받습니다.
  - `S4CCM_Setup_v버전.exe`: 설치 파일.
  - `S4CCM.zip`: 포터블용

## 5. 파일 설명

### 설정 폴더: `%APPDATA%\S4CCM`

| 파일 | 내용 |
|---|---|
| `config.json` | 설정 (심즈4 폴더, 게임 실행 파일, 테마 등) |
| `s4ccm.db` | CC 목록, 분류, 메모, 자동 정리 기록 |
| `thumbs\` | 썸네일 이미지 |
| `crash.log` | 오류 기록 (최대 1MB) |

### 심즈4 폴더 안에 생기는 것

| 폴더/파일 | 내용 |
|---|---|
| `S4CCM_Disabled\` | 비활성화한 CC (게임은 읽지 않음) |
| `S4CCM_Quarantine\` | 충돌 테스트 중 잠시 빼 둔 CC |
| `S4CCM_Backups\` | Resource.cfg를 저장할 때 만든 백업 |
| `Options.ini.s4ccm.bak` | 게임 옵션을 바꿀 때 만든 백업 |
